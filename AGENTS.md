## Agent skills

### Issue tracker

Issues and specs live as markdown files under `.scratch/<feature>/` in this repo. See `docs/agents/issue-tracker.md`.

### Triage labels

Decision tickets use `open`/`claimed`/`resolved`; implementation tickets use `ready-for-agent`/`ready-for-human`/`in-progress`/`closed`. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context: `GLOSSARY-MAP.md` at the repo root points at one `GLOSSARY.md` per context (`framework/`, `extensions/<id>/`); `docs/adr/` and `docs/agents/` stay at the repo root. See `docs/agents/domain.md`.
