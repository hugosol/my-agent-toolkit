# Pstack Suite

本上下文区分上游原始资料、本地适配及向宿主交付的资源。

## Language

**上游快照（Upstream snapshot）**：套件选定的上游资源在某一固定提交中的原始内容，不包含套件的本地适配。
_Avoid_: 最新上游、生成版本

**快照基线（Snapshot baseline）**：标识上游快照来源的仓库、固定提交与版本；不代表上游当前最新状态。
_Avoid_: 当前上游版本

**资源清单（Resource manifest）**：明确选择套件交付资源及其来源的清单；上游未被选中的资源不属于套件的更新范围。
_Avoid_: 全量上游目录

**本地适配（Local adaptation）**：套件有意施加在上游快照之上的改动，每项具有独立的名称与原因。
_Avoid_: 上游更新

**交付资源（Delivered resource）**：套件提供给宿主消费的文件，包括经本地适配的上游资源和套件自有资源。
_Avoid_: 上游快照
