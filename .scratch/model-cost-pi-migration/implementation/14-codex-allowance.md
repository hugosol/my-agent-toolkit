## Acceptance criteria

- [ ] 独立报告覆盖位置互换、单窗口、缺读数、失败和重置时刻 unknown/expired/invalid/valid；缺失不变零，不重定时旧读数。
- [ ] 手算数字覆盖 50 点阈值、两窗口增长、饱和、不配对更新、baseline 和 refinement；不把合并的新旧窗口凑样本。
- [ ] 验证 baseline 即时保存、refinement 既定限频和较新文档合并，新进程恢复；消费周期变化不清估计。
- [ ] 实际宿主证明认证/endpoint/结算触发接线；真实账户侧读数确认由 24 负责，不用可控报告冒充账户事实。
- [ ] **P30 完整 Coverage（S2）**：独立报告覆盖位置互换、单窗口、缺读数、重置时刻状态与失败；实际宿主验证接线，不把缺失变零或重定时旧读数。真实账户侧确认另见 P53。
- [ ] **P31 完整 Coverage（S2、S3）**：独立数字验证阈值、饱和、不配对更新、baseline 与 refinement 保存规则；消费重置后估计不清空，不能把合并后的新旧窗口凑成样本。
