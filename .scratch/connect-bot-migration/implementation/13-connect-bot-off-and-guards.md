# 13: `/connect-bot off`、未接入零动作与未知参数

**What to build:** `off` 先本地立即断开（停心跳、清状态与队列），再尽力让面板移除该行；面板可达（含 omp-bot 重启后的 404）提示「已断开」，不可达/超时提示「面板未响应」。未接入（含刚 off 之后）的会话零动作；未知参数报错且状态不变（`off` 现在合法，不再有 `offline` 别名）。

**Delivers:** P28, P29, P36（清除部分）, P37（off/未接入文案部分）, P26（off 后归零部分）, P27（off 的门槛部分）

**Test owner for:** P28、P29

**Blocked by:** 11

**Status:** ready-for-agent

- [ ] `off` 先本地断开（停心跳、清状态与出站队列、清自持记录），再 best-effort 注销；本地停止先于任何网络等待
- [ ] 面板可达（2xx 或 404）→ 提示「已断开」；reject/超时（≤1.5s）→ 提示「面板未响应」；两种情况下本地都已断开
- [ ] off 后 marker 消失、无残留 timer/请求；off 之后会话回到「未接入零动作」
- [ ] 未接入时执行 off 是静默 no-op：不发请求、不通知
- [ ] 命令表面只有一个词形：空参 = on、`off` = off；`offline` 不再合法（其提示文案失效，统一为 `off`）
- [ ] 未知参数报错且状态不变
- [ ] 门槛对 off 同样生效：子代理静默拒绝、无 UI 走 stderr，且不改状态、不发请求
- [ ] E 层测试覆盖以上（含 404 与超时两条分支、未接入 no-op）
