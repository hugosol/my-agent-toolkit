# 10: 版本准入与显式拒绝

**What to build:** 准入检查只发生在扩展装载/绑定、注册命令与贡献之前，且唯一准入检查是版本：`supportedVersions: ["18.5.0"]` 精确枚举而非范围。未列版本 → 每个 main 会话一次非模型通道通知（无 UI 走 stderr 一行）后继续运行、不声明支持；必须语义缺失（如历史保护无法满足）→ 显式拒绝该能力、放弃 binding、不留部分注册，且拒绝优先于「未列版本继续运行」。platform/runtime 只记录为已验证环境、不作门槛。两条触发不得混同；反馈绝不写入模型指令或会话历史。拒绝路径用可注入的测试 adapter 真跑。

**Delivers:** P24、P25、P26、P27、P28

**Blocked by:** 03、06

**Status:** ready-for-agent

- [ ] 支持集是精确版本枚举（非范围）；18.5.0 不触发任何准入反馈（C13）
- [ ] 未列版本：每个 main 会话一次 `warning` 通知，无 UI 走 stderr 一行，随后继续运行、不声明支持（N1）
- [ ] 必须语义缺失：显式拒绝、放弃 binding、不留部分注册（N2、C14），用可注入 test adapter 真跑，不只验通道存在
- [ ] 「必须语义缺失 → 拒绝」优先于「未列版本 → 继续运行」，两者不混同（C14）
- [ ] 通知/告警走非模型通道，绝不进入模型指令或会话历史（C14）
- [ ] platform / runtime 只记录，不作准入检查、不告警（C13）
- [ ] 通知去重键 = 每个 main 会话一次，重复装载/重入不刷屏
