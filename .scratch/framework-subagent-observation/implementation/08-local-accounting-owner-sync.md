# 08: 子会话自行记账，Owner 按成功提示或重连同步

**What to build:** 响应 usage 只由实际执行会话累计并保存；Owner 的远端观察和重连不重复计费或代写。确认提交成功后发送提示，Owner 只读采用消费文件实际内容；丢失提示后，有效重连仍触发只读同步恢复记录。

**Delivers:** P16, P17, P19

**Blocked by:** 05 — 重连恢复快照，失效撤销读数但保留身份。

**Status:** ready-for-agent

依据：[已批准 contract](../contract.md)、[spec](../spec.md)。本票拥有 P16、P17、P19 全部 coverage 与测试，保持活动消费文档为唯一消费权威，不通过 IPC 累计快照建立第二套账。

- [ ] 使用独立给定的两会话 usage 算例核对 Direct session totals 与 Inclusive session totals，每笔请求仅计一次；远端观察、快照和重连不产生重复累计。
- [ ] 实际子进程提交证据与 Owner 同步行为共同证明写者归属，Owner 不代写子记录。
- [ ] 阻止 Owner 自身消费提交后，子会话保存仍使 Owner 看到新记录；Owner 接收成功提示只读采用文件内容，不采用提示携带的消费累计，不产生写入。
- [ ] 失败保存不发送成功提示；成功提示只在确认提交后发生，不把开始保存或停止等待当作成功。
- [ ] 丢弃一次成功提交提示，断开再接入；Owner 无自身消费或提交仍能通过只读同步看到文件中的新记录。
- [ ] 只读同步复用存储基线与既有失败政策，不变成初始化、强制保存或轮询，不为观察或重连重放 Turn／Round。
- [ ] 按仓库测试规范执行计费、存储及受影响消费者分区，TypeScript 变化执行 typecheck；通过真实进程、存储访问／提交证据和实际 Owner 表面验收并记录限制。
