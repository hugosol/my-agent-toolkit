# 11: 合并消费同步，并由重连补齐丢失提示

**What to build:** Owner 合并多个提交提示的只读同步，同时保留同步期间到达的新刷新需求；有效重连主动同步消费文件，即使上次成功提交提示丢失也能采用最新记录。

**Delivers:** P18, P19

**Blocked by:** 10：成功提交后只读采用消费，保持写者、周期与清理顺序

**Status:** ready-for-agent

- [ ] 多个提交提示合并刷新，记录提示数和同步数，证明不是每条提示独立重复读取完整文档。
- [ ] 受控暂停一次同步，期间再实际提交并通知，恢复后最终采用独立给定的最新记录；没有永久漏刷，合并调度不丢最后一次刷新需求。
- [ ] 明确丢弃一次成功提交提示，断开后再接入；Owner 无自身消费或提交仍读到文件新增记录，重连同步不以先前收到提示为条件。
- [ ] 在真实进程与实际 detail 中观察最终采用结果，核对文件权威和只读性质；不增加轮询、自动重试或用远端消费快照代替文档。
