# 12: Owner 不可达时仍本地保存并有界退出

**What to build:** Owner 缺失、断开或不回应不影响真实子会话本地结算和有界退出；通知是已成功保存后的尽力交付，不要求 Owner 确认或完成绘制。

**Delivers:** P32

**Blocked by:** 02：统一收口截止与准确保存诊断；10：成功提交后只读采用消费，保持写者、周期与清理顺序

**Status:** ready-for-agent

- [ ] 分别制造 Owner 缺失、接入后断开及连接存在但 Owner 不回应，真实子进程均能完成自身本地文件提交和退出。
- [ ] 独立给定 usage 对照实际消费文件；同时记录提交、诊断、进程退出和等待时序，不仅检查进程 exit code。
- [ ] 保存与退出没有等待 Owner 确认、同步或绘制的依赖；Owner 不回应也不能使退出超出共同收口预算而无限等待。
- [ ] 通知失败不回滚已成功保存文件，不伪报本地保存失败；本地保存失败或截止仍沿用准确的失败/结果未确认诊断。
- [ ] 不通过新增心跳、看门狗或强杀前保存保证满足本票；不从断连推断任务成功或失败。
