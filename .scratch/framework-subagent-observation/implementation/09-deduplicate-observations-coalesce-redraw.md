# 09: 去重观察发布并合并终端重绘

**What to build:** 事件驱动采集和发布避免相同读数重复通知；多个会话和字段的一批可合并更新保留各自最新结果，同时减少不必要的终端重绘。

**Delivers:** P14, P15

**Blocked by:** 07：两种进程模式的当前观察交付与完整接线

**Status:** ready-for-agent

- [ ] 固定事件序列、重复值、静止窗口和流式响应分别记录实际通知次数与内容，证明不逐 token 发布、不持续轮询、相同读数不重复发布。
- [ ] 受控交付多个会话和字段的更新，同批每个会话每个字段的最新结果均被保留，且有实际合并重绘证据。
- [ ] 实际终端观察与测量分别记录采集/通知成本和绘制成本，不从最终截图推断通信频率，不承诺未经测量的零开销。
- [ ] 内存及时采用事实，重绘合并不丢弃或延迟应影响本地结算的生命周期事实；不增加耗时持续跳动或其他轮询流量。
