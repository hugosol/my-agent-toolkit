# 06: 后台主动登记身份并形成真实代理树

**What to build:** 实际后台子会话取得可靠身份后即主动出现在 Owner 的 detail 中，不等完成通知或首轮消费提交；后代直接交付 Owner，代理树仍按真实直接父关系排列，同一实际 session 不因 run 或进程变化重复出现。

**Delivers:** P1, P2, P3, P9

**Blocked by:** 03：通过共同观察展示正确 Working/Idle；05：受校验的本机接入与 Owner 当前 State 只读访问

**Status:** ready-for-agent

- [ ] 实际后台会话首轮结束前可见，登记身份与独立宿主事实相符；无法可靠解析 Owner 时不从名称、目录形状或 PID 猜测。

- [ ] 同一实际 session 通过两个 run/来源交付，实际 detail 始终只有一行；实际 session、提供方 run 和进程身份不混用。
- [ ] 实际 detail 在首次提交前展示给定非零上下文及可靠身份；缺失消费保持缺失，不呈现为确认零。复用现有可靠读数或共同消费能力，不另增并行原生采集路径。
