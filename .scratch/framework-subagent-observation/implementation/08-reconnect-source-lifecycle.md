# 08: 重连恢复快照并隔离迟到、失效来源

**What to build:** 断开后重连恢复最新观察而不重放计费生命周期；旧来源、迟到消息和旧连接关闭不使读数倒退。来源失效撤销实时值，但保留可靠身份、直接父关系和已保存消费。

**Delivers:** P5, P6, P7, P8

**Blocked by:** 07：两种进程模式的当前观察交付与完整接线

**Status:** ready-for-agent

- [ ] 断开期间状态变化，再有效重连，立即收到最新可用快照；没有额外 Turn/Round 交付或凭快照补账。
- [ ] 真实进程交付重复、可控迟到序列与旧来源关闭，最新给定值保持；使用明确屏障或受控交付排序，不依赖概率性 sleep。
- [ ] 正常来源撤销与子进程异常退出分别验证；接收侧观察关闭或错误即可使来源失效，不依赖子进程成功发送最后消息。
- [ ] 共同读取不可用、实际 detail 不残留 Working 或实时上下文；失效不伪造 Idle、任务失败、完成或成功。
- [ ] 断连前后对照树和已保存消费，可靠身份及直接父关系不被删除；只有实时登记、尚未提交的身份在本次 Owner 运行中保留，不新增身份持久化。
- [ ] 旧连接关闭不能清除更新有效来源的读数；并发来源切换和重连场景同时验证来源归属。
