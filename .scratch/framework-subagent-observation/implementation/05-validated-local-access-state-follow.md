# 05: 受校验的本机接入与 Owner 当前 State 只读访问

**What to build:** 子会话通过 framework 已有本机接入读取 Owner 当前权威 follow 值；接入隔离完整目标及有效寿命，仅开放声明的读取和观察，不授予远端写 State 能力。

**Delivers:** P21, P22, P25, P26

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 在实际跨进程初始与后续语义使用中验证 Owner 值由 true 改 false 后子会话取得 false；同进程直接读当前值，不退化为永久启动快照。
- [ ] 一次语义处理内相关读取可共用取得的快照；不可达时沿用既有默认与恢复政策，并区分默认回退和成功取得权威值。
- [ ] 真实子进程使用错误扩展、错误 Owner 和旧接入校验均被拒绝；两个并发 Owner 的独立给定值不串接，诊断不泄漏校验材料。
- [ ] 读取及允许的声明观察交付不会改变 Owner 给定 State；错误方向、未声明操作及远端 State 写入被拒绝，不引入任意 RPC。
- [ ] 实际定位记录只承载发现与接入校验所需元数据，不存 State 或观察值；地址及 PID 不作为身份或存活证明，记录随接入寿命释放。
- [ ] 使用显式 runtime directory；相对配置按共享配置自身目录解析，缺失或非法不回退到 cwd、临时目录或消费存储根。通过真实文件内容与变动观察证明没有文件消息队列或目录扫描接收。
- [ ] 复用既有 framework 本机接入与平台载体；仅 follow 的接线证据不替代后续子会话完整观察验收，接线后受影响安全用例继续回归。
