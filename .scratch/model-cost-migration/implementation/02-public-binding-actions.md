# 02: 公共工厂生命周期与 actions 路由

**What to build:** 扩展通过同一公共声明与工厂获得已校验配置、一次初始化、完整清理和可等待的动作执行；现有调用方继续可用。

**Delivers:** P28, P56

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 公共 authoring 信息从 OMP 专属类型独立，复用既有公开入口；配置读取/校验先于工厂，工厂创建时不发远端请求或启动 timer。
- [ ] 认证可读节点初始化一次，首模型请求等待初始化收口；绑定失败清理已创建资源，卸载/结束停止交付、解绑订阅、失效旧访问并只清理一次。
- [ ] 普通模型/Session/tree/查看变化不销毁 CLI 业务实例；一般异步保存不成为后续事件或输入屏障，同步异常和 Promise rejection 均被承接。
- [ ] actions 去空白、忽略大小写并完整匹配；空参帮助，缩写/额外参数/非法参数 error 加同一帮助且不执行，不借 directed.unrecognized。
- [ ] 宿主链等待同步或异步 action 完成，未处理错误只报告一次，不自动重试/回滚或先通知成功；命令阶段业务验证由 19 负责。
- [ ] 本票变更公共契约时，同票迁移全部受影响调用方及有效行为 tests，保持 CI 可用；不得将编译修复推迟到 22/23，不留旧装配类型或兼容转发双轨。
- [ ] 通过生产公共绑定与受控 adapter 验证配置→工厂→初始化顺序、生命周期、动作语法和异步承接，并在隔离真实 loader/RPC 验证加载、命令及清理。
- [ ] 通过批准的生产公共 seam 观察行为，预期来自合同/规格、独立字面值或手算，不以被测实现重算；永久网络 tests 使用 mock。
- [ ] 使用隔离安装/配置/工作/Session/数据根，不操作正式 OMP；承接异步失败并保留够用脱敏证据，完成本票自动检查及材料准备，不因计划人工验收暂停可执行工作。

## Verification responsibility

本票负责所列 Delivers 的自动 coverage 与适用宿主贯通/证据准备；P58/P52 按本票具名责任执行。合同采用 Rapid iteration：H1/H2 及允许的条件性 H3 按原 Coverage 交用户确认，未确认不记通过；不改变承诺或免除实现/永久 tests。
