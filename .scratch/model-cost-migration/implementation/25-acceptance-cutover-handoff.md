# 25: 独立兼容性证据与人工切换交接

**What to build:** 用户获得范围明确的独立验证记录、剩余人工场景及安全手动切换/回退清单，不将绿色测试误作完整迁移认证。

**Delivers:** P60, P61, P62, P63, P64

**Blocked by:** 24: 生产架构清理与完整持久化验证

**Status:** ready-for-human

## Acceptance criteria

- [ ] 运行既有独立验证，记录精确宿主版本/revision/artifact、framework/extension 源码 revision、依赖/lockfile/环境和验证范围；正常启动无版本/shape/report 门禁，保留必要配置和业务失败。
- [ ] 从首票起保持独立安装/进程/配置/工作/Session/数据根，本票核对全部验证隔离证据；不向正式 OMP 发验证命令、重启、更改配置/加载/凭证或统计。
- [ ] 汇总必需 tests、本地传输/文件/进程 smoke、OMP 脚本、少量真实 smoke 与 H1/H2，逐项区分通过/失败/跳过/待人工；mock/RPC/发现结果不能认证真实服务或视觉。
- [ ] H1 场景及材料来自 P11/P23/P26/P27/P41/P67 对应 delivering tickets；H2 来自 P36/P38/P39/P65/P66，沿合同核对，缺证据不判通过。
- [ ] H3 仅对应合同允许条目的真实 OMP 脚本多次失败或成本明显过高时转交；保留具体场景、尝试/原因、步骤、独立预期和自动结果，永久 tests 仍完成，无转交就无人工项。
- [ ] 全部实现/自动检查先完成再人工轮；准备充分材料后明确列剩余确认，未获用户确认仍未验证，不把票的代理工作完成等同承诺整体通过。
- [ ] 交付用户手动停机/备份旧配置统计/空数据准备/旧新加载互斥/启动/正式确认清单；失败停新实例、保留新数据排查、恢复旧配置备份后重启，不合并新旧统计。
- [ ] 仅隔离演练切换/回退，不自动迁移/删除旧数据或执行正式切换；维护者按完整证据明确支持，不预造或扩大支持声明。
- [ ] 具体缺口带脱敏证据请求裁决并记录未决，不静默删功能/缩范围或重开已批准原则扩建假想机制；真实秘密不进入对话、日志或 tracker。
- [ ] 通过批准的生产公共 seam 观察行为，预期来自合同/规格、独立字面值或手算，不以被测实现重算；永久网络 tests 使用 mock。
- [ ] 使用隔离安装/配置/工作/Session/数据根，不操作正式 OMP；承接异步失败并保留够用脱敏证据，完成本票自动检查及材料准备，不因计划人工验收暂停可执行工作。

## Verification responsibility

本票负责所列 Delivers 的自动 coverage 与适用宿主贯通/证据准备；P58/P52 按本票具名责任执行。合同采用 Rapid iteration：H1/H2 及允许的条件性 H3 按原 Coverage 交用户确认，未确认不记通过；不改变承诺或免除实现/永久 tests。
