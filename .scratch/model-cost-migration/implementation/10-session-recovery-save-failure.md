# 10: Session 恢复、导航与保存失败收口

**What to build:** 重启和会话导航如实恢复当前周期消费；保存失败不阻断模型，也不重交丢弃消费或猜历史 Round。

**Delivers:** P16, P17, P18, P19, P46

**Blocked by:** 08: 工具续跑与轻量 Round 累计；09: 实际 Session 自身归属与父树汇总

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 正常保存后独立重启恢复已保存自身聚合、当前周期与版本，不扫描宿主历史/归档、不重算、不维护 lifetime。
- [ ] tree 历史位置往返及继续执行不回滚已发生消费；缺可靠运行期快照的重启/tree/reload 不展示伪历史 Round，文件差值不冒充轮次。
- [ ] fork 新实际 Session 自身从零，复制消息不产生消费且不改原累计；发生真实新请求后只新增本 Session。
- [ ] 普通保存故障明确报告，丢弃受影响未保存段，恢复完整有效磁盘周期/Session/版本；不置零、不清 holiday/已处理标记、不自动重交。
- [ ] 无有效基线按 06 暂停政策，不将普通保存恢复政策自动用于命令/estimate；不增加双执行者租约或异常账本。
- [ ] 用生产入口故障场景、真实文件读回和独立重启验证有效 baseline/版本，隔离 OMP 证明故障后真实模型继续及导航/fork 结果；金额预期独立。
- [ ] 通过批准的生产公共 seam 观察行为，预期来自合同/规格、独立字面值或手算，不以被测实现重算；永久网络 tests 使用 mock。
- [ ] 使用隔离安装/配置/工作/Session/数据根，不操作正式 OMP；承接异步失败并保留够用脱敏证据，完成本票自动检查及材料准备，不因计划人工验收暂停可执行工作。

## Verification responsibility

本票负责所列 Delivers 的自动 coverage 与适用宿主贯通/证据准备；P58/P52 按本票具名责任执行。合同采用 Rapid iteration：H1/H2 及允许的条件性 H3 按原 Coverage 交用户确认，未确认不记通过；不改变承诺或免除实现/永久 tests。
