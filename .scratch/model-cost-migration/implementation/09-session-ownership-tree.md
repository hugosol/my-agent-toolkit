# 09: 实际 Session 自身归属与父树汇总

**What to build:** 主、子、孙和兄弟请求各自归入实际发起 Session，主树汇总不重复，最新名称不改变身份。

**Delivers:** P12, P13, P24

**Blocked by:** 07: 请求锚价与可靠 usage 记账

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 唯一消费源为 harness+实际 Session×provider×model 自身聚合；不按 Owner、当前查看目标、名称或报告层级入账，task/orchestration 报告不再计费。
- [ ] 保存可靠直接父关系，沿父链汇总每份自身贡献一次；不从父总数反推子贡献，不要求父先保存或造占位父。
- [ ] 构造异构主/子/孙/兄弟且整树与自身预期故意不同的数据，独立手算 token/Cost/Ref，验证在途切查看仍进入原发起桶。
- [ ] 名称按实际身份持续更新，包括未查看子/孙；不可取得不猜名称或覆盖已知名称；内存/展示即时变化，只在下次正常消费保存写文件，不额外触发保存。
- [ ] 通过 S1 身份/直接父事实、S2 展示和真实保存读回验证；隔离宿主脚本覆盖实际代理关系与查看切换，不将 Owner 过滤再次套在记账组。
- [ ] 通过批准的生产公共 seam 观察行为，预期来自合同/规格、独立字面值或手算，不以被测实现重算；永久网络 tests 使用 mock。
- [ ] 使用隔离安装/配置/工作/Session/数据根，不操作正式 OMP；承接异步失败并保留够用脱敏证据，完成本票自动检查及材料准备，不因计划人工验收暂停可执行工作。

本票负责所列 Delivers 的自动 coverage 与适用宿主贯通/证据准备；P58/P52 按本票具名责任执行。合同采用 Rapid iteration：H1/H2 及允许的条件性 H3 按原 Coverage 交用户确认，未确认不记通过；不改变承诺或免除实现/永久 tests。
