# 15: 并行初始化、当次鉴权与非阻塞调度

**What to build:** 每 CLI 并行预取已配置 provider，首次请求有限等待，后续查询不挡执行；凭据只用于当次操作，旧实例结果不再产生效果。

**Delivers:** P37, P40, P53

**Blocked by:** 12: DeepSeek 余额成功 TTL 与在途合并；13: Codex 响应 headers 与独立额度窗口

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 认证可读时一次并行预取已配置 DeepSeek/Codex，缺源不查，不依赖当前模型；首模型请求前成功/失败/超时有限收口，允许先输入且失败不阻断模型。
- [ ] 同 CLI 子共用缓存/初始化，独立 CLI 各自独立；切模型/Session/tree/查看不全量预取或销毁有效缓存。
- [ ] 每次操作读取并固定当次已生效凭据及必要地址，替换不改在途操作；凭据/OAuth/原生接入失败只影响对应查询，不跨凭据借用、不填零。
- [ ] 运行期悬挂网络不阻下一模型请求、工具、idle 或退出；通知时重读当前目标，销毁后迟到结果不反馈/重绘/进入新实例，不新增主动 HTTP 取消或退出排空。
- [ ] 合成秘密哨兵验证正确目标/鉴权、当次固定和局部失败；错误、日志、模型内容、文件与证据不含秘密，真实秘密不进入对话。
- [ ] 通过公共绑定、S2、mock 网络及隔离实际 OMP 请求顺序验证并行/首请求门槛/非阻塞/销毁；使用网络悬挂场景而非仅 Promise 不抛断言。
- [ ] 通过批准的生产公共 seam 观察行为，预期来自合同/规格、独立字面值或手算，不以被测实现重算；永久网络 tests 使用 mock。
- [ ] 使用隔离安装/配置/工作/Session/数据根，不操作正式 OMP；承接异步失败并保留够用脱敏证据，完成本票自动检查及材料准备，不因计划人工验收暂停可执行工作。
