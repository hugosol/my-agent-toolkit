# 01: 公共 HTTP 全请求取消与兼容

**What to build:** 公共 HTTP 调用方能够取消从请求开始到正文接收完成的整个传输，实际释放资源；既有消费者继续得到已承诺的完整响应与错误信息。通过 S2 交付，不引入 Run 协议或角色专用传输平台。

**Delivers:** P20、P25

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

依据：[获批契约](../contract.md)及其继承的 spec。仅交付 toolkit，不修改后端、不新增自主重试或第二套状态机。

## Acceptance criteria

- [ ] 预先取消不发起传输；连接、等待响应和正文读取期间取消均实际清理对应资源，不能仅提前返回而留下活动请求。
- [ ] 调用方取消与客户端超时可辨识；终止条件竞争时报告实际采用的原因，不增加全局优先级规则。
- [ ] 覆盖受影响消费者的成功／非 2xx 完整正文、原超时、配置错误与传输错误；同步迁移公开错误分类消费者，不保留主动取消被归类为超时的旧行为。
- [ ] 若改动直接连接或代理行为，观察对应实际传输；保持现有配置失败不静默回退的行为。
- [ ] 通过公共 HTTP interface 和独立预期验证，保留资源释放证据；运行所属测试分区、受影响消费者检查及 TypeScript typecheck，更新公共能力权威说明。

## Coverage ownership

本票独占 P20、P25 的契约测试。07 拥有 S1 真实 omp 生命周期接通与后端等待释放检查，不以本票受控 HTTP 证据代替。03 可以先使用已有公共 HTTP；本票合入时同步迁移届时受影响的消费者，共享文件协调不构成额外业务阻塞。
