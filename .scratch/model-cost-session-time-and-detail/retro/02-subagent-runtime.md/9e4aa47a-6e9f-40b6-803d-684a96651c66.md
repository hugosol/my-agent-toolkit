## 1（最高）worktree 检出把 `host-patches/*.diff` 变成 CRLF，dock 分区整体跑不起来
- 事实：`bun test tests/harness-dock/model-cost-persistence.test.ts` 首先失败于 `host-patches/omp-18.5.0-viewed-session/patch.diff touches no file`；`od -c` 显示该文件为 CRLF（27184 字节），主仓同类检出为 LF（26585 字节）；`sed -i 's/\r$//'` 归一化后同一用例 24.1s 通过。仓库根清单中无 `.gitattributes`。
- 影响：真实宿主证据（本票 P10 的硬性要求）在票据 worktree 内等同不可运行；报错只说 “touches no file”，不提示行尾。
- 建议：加 `.gitattributes`（`*.diff text eol=lf`；fixtures 同类文本一并处理），并在 `patchTouchedFiles` 的空结果分支错误文本里写明“未解析到 `+++/---` 路径，文件可能含 CRLF”。
